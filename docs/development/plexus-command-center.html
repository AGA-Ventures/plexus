03

Architecture

One governed core, clear module boundaries. The current modular monolith keeps identity, tenancy, authorization, data, and operations coherent while capabilities use stable server and domain interfaces.

Trust boundary

The browser is untrusted. Trusted role bindings live in Auth app metadata, server checks validate the active identity, and Postgres RLS enforces tenant and company scope.

Evolution rule

The modular monolith remains the preferred shape until measured scaling evidence justifies extraction. New capabilities must satisfy the documented module contract.
